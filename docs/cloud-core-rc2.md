# Cloud core RC2
Dedicated D1 database in EU, schema in database/cloud-core.sql. Bind CLOUD_DB only to lts-cloud-core after CI. The owner session protects every endpoint; mutating requests require exact origin. Store at most 20 files of 64 KiB, attachment downloads with SHA-256 verification; no arbitrary SQL, no public files. Suitable only for small nonsensitive artifacts. R2 not activated because billable overages cannot be ruled out. D1-managed recovery is distinct from independent encrypted backup; no restore action or schedule enabled. Monitor reports actual Worker and D1 query status, not server hardware metrics. PostgreSQL, server runner, hosting orchestration and private GitHub access remain separate. No project migration.
